## Pipeline Big Data End-to-End — Ingestion & Streaming

Academic project at Polytech Intl (2024–2025) · Dataset: **NYC Taxi Trips** · Platform: **Cloudera CDH**

### Architecture

Design and deployment of a massive data pipeline on Cloudera CDH:

- **Real-time streaming** with Apache Kafka
- **Batch transfer** MySQL → HDFS via Sqoop
- **Log ingestion** via Flume
- **Distributed storage** on HDFS
- **Orchestration** with ZooKeeper
- **Processing** on Hadoop

### Tech Stack

- Apache Kafka
- Sqoop
- Flume
- HDFS
- MySQL
- ZooKeeper
- Hadoop CDH
- Linux

### What I learned

- Designing end-to-end Big Data pipelines
- Real-time vs batch data ingestion patterns
- Working with the Hadoop ecosystem on Cloudera
- Managing distributed storage and orchestration
