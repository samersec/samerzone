## Gestion Des Services Hospitaliers — Hospital Management Platform

A complete hospital service management web application · Dec. 2024 – Present

> 🔗 **[Live Demo](https://gestion-des-services-hospitalier-fr.vercel.app/login)**

### Features

- **Appointment management** — scheduling and tracking patient appointments
- **Medical records** — centralized patient dossiers
- **Pharmacy inventory** — stock management and tracking
- **Donations** — donation tracking and management
- Full CRUD operations across all modules

### Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS, Vite
- **Backend:** Spring Boot (Java)
- **Database:** MongoDB

### What I learned

- Building complex multi-module healthcare applications
- Spring Boot + MongoDB integration
- Modern frontend with React + TypeScript + Tailwind + Vite
- Managing multiple interconnected services in a single platform
