## Beem Smart Taxi — Multi-Role BI Dashboard

Built during PFE internship at **SWIFTECH** (Feb – May 2024). A multi-role Business Intelligence dashboard for a smart taxi platform.

> 🔗 **[GitHub Repository](https://github.com/samersoltanii/Dashboard-Beem)**

### Roles

- **Admin** — full platform overview, KPIs, analytics
- **Driver** — trip management, performance stats
- **Client** — booking history, trip tracking

### Features

- Interactive KPI visualization and decision support
- REST API design with role-based access control
- User role management and performance optimization
- Real-time data charts and analytics

### Tech Stack

- **Frontend:** ReactJS, TypeScript, Chart.js
- **Backend:** Node.js, Express
- **Database:** SQL

### What I learned

- Building multi-role BI dashboards with complex data visualization
- Chart.js integration for interactive analytics
- REST API design with Express.js
- Performance optimization for data-heavy applications
