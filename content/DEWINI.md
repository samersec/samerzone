## DEWINI — AI-Powered Medical Data Management

> 🏆 **1st Prize — Hackathon 1.0: From Idea to Startup** (March 2025)

A healthcare web platform connecting doctors and patients, built during an engineering internship at **Dream Tek Consulting** (2025).

### Features

- Centralized medical records management
- Doctor-patient platform with secure data handling
- Secured REST APIs with role-based access
- MVC architecture for clean separation of concerns
- AI-powered medical data analysis

### Tech Stack

- **Backend:** Spring Boot (Java)
- **Database:** MySQL
- **API:** REST API
- **Architecture:** MVC

### What I learned

- Building production-ready healthcare applications
- Securing sensitive medical data with proper API design
- Working with Spring Boot in a professional environment
- Winning a hackathon by delivering a complete, impactful solution
